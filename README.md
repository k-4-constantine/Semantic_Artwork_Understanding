# Semantic_Artwork_Understanding

The prompt-image relationship is the topic *du jour* in text-to-image generation studies. While past research explored individual lexical cues, semantic-level prompt
 structures remain understudied. This study distinguishes three types of information in prompts, content, style, and context, and evaluates their respective roles in guiding Stable Diffusion models to regenerate fine art paintings. Using the SemArt dataset, six prompt variations with different information subsets were generated. More than 16,000 images were generated and evaluated using CLIP, LPIPS, and SSIM. The results suggest that full prompts generally outperform others, with metadata (author and title) contributing significantly. Prompts act as dynamic semantic units, where individual tokens influence both global content and style. Additionally, output consistency is type-dependent, with similar artworks tending toward normative representations. These findings offer new insights into semantic prompt engineering and quality control of generation
